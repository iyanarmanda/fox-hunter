# Fox-Hunter

## About

**Fox-Hunter** is a digital forensics triage CLI tool for Firefox browsers (Gecko based) on Linux Operating Systems. Built with Rust to accelerate incident investigations.

### Built with

- [Rust](https://rust-lang.org/)
